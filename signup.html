  1. Sign in to the dashboard: Messenger login. The same account works from Python and in the game.
  2. Install the Python API (public, Python 3.11 or newer) and sweep your first memristor: 
    pip install git+https://github.com/vonneuro/messenger-api.git

from vonneuro_messenger import MessengerClient
c = MessengerClient("https://hub.vonneuro.com")
c.login("", "your-password")
iv = c.memristor_array(3, amplitude=0.25)["memristor"]
    Its README lists every method. No Python installed? The Python lab runs the same code in your browser.
  3. Watch your email for GitHub's invitation to vonneuro/messenger (for ), the repository with the runnable examples and the full bench manual. We send it by hand, usually within a working day.
  4. Need more than your weekly hour? Ask from Usage on the dashboard.
