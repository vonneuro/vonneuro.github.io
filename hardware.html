Devices on the network

Each device listed here is a physical system in the laboratory that owns it, connected to vonNeuro Messenger by an agent on an adjacent computer. A device declares its operations with typed, bounded parameters. A job is checked against those bounds by the hub, and again by the owner's driver before anything is driven; the result returns with its raw data. Status and 30-day usage below are read from the hub when the page loads.

Running an operation from Python

pip install git+https://github.com/vonneuro/messenger-api.git

from vonneuro_messenger import MessengerClient
c = MessengerClient("https://series-marina-gigantic.ngrok-free.dev")
c.login("you", "your-password")

array = c.device("admin/memristor-array")
print(array.operations["iv_sweep"]["params"])          # every parameter with its range and unit
iv = array.run("iv_sweep", channel=3, amplitude=0.25, frequency=10)["memristor"]

The same calls run in the VS Code extension and in the browser's Python lab, where client is already signed in. The worked examples show complete scripts and the output they printed on the bench devices listed here.
