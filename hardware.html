vonNeuro network · hardware

Hardware you can reach.

Every device here is a physical system in someone's laboratory, connected through vonNeuro Messenger. Each one lists the operations it offers, with typed and bounded parameters; you send a job, the owner's computer runs it on the hardware, and the measured results come back to you. The owner's driver decides what is safe, so the hardware keeps its own limits.

Run one from Python

pip install git+https://github.com/vonneuro/messenger-api.git

from vonneuro_messenger import MessengerClient
c = MessengerClient("https://series-marina-gigantic.ngrok-free.dev")
c.login("you", "your-password")

array = c.device("admin/memristor-array")
print(array.operations["iv_sweep"]["params"])          # every parameter with its range and unit
iv = array.run("iv_sweep", channel=3, amplitude=0.25, frequency=10)["memristor"]
